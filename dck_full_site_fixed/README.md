# DCK$ — Digital Currency Kids

This is the official site repo.

## 🚀 How to Run
1. Upload this folder to GitHub as a repo.
2. Connect repo to Vercel → [https://vercel.com/new](https://vercel.com/new)
3. Add your domain `dcktoken.com` in Vercel settings.
4. Replace images in `/assets/` with your crew art.
